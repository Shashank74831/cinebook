# 🎬 CineBook – Genre Management API

CineBook is a movie-focused REST API built using **Node.js and Express.js**.  
The project demonstrates how to build and organize APIs using the **MVC (Model-View-Controller) architecture**.

The API allows users to view all movie genres, search for a genre by ID, and add new genres.

---

## 🚀 Features

- 🎭 Get all movie genres
- 🔎 Get a specific genre by ID
- ➕ Add a new movie genre
- ✅ Request validation
- ❌ Proper error handling
- 📊 JSON-based API responses
- 🏗️ Clean MVC project structure

---

## 🛠️ Technologies Used

- **Node.js**
- **Express.js**
- **JavaScript (ES Modules)**
- **REST API**
- **Thunder Client / Postman**
- **Git & GitHub**
